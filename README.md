## 최종적으로 해결한 문제

메신저 기반의 학교 업무 시스템을 하나로 묶어 효율적으로 만들기 위해 노력하였습니다.

### 어떻게 풀었나요?

공유 캘린더를 기반으로 업무 담당자가 공지 등 필요한 업무 유형에 맞게 일정을 등록하고, 업무를 수행해야 하는 선생님들이 캘린더 화면으로 나의 일정을 정렬해서 볼 수 있게 하였습니다.

## 핵심 기능

- **메신저 기능**: @멘션 기능을 이용해 별도의 조직도가 없어도 사용자에게 1:N 쪽지를 발송할 수 있어요.
- **그룹 기능**: 공용 그룹과 사용자 맞춤형 그룹으로 나눠져 있어요. 쪽지, 공지, 일정 등을 저장할 때 @그룹으로 일괄 정보를 전송/등록할 수 있어요.
- **리마인드 기능**: 해야할 일을 D-day 순으로 목록화해서 사용자가 잊지 않도록 알려줘요.
- **알림 기능**: 사용자가 잊지 않도록 주기적으로 알림을 줘요. 알림이 남아있다면 큐브 모양 위에 뱃지 알림이 있어서 화면 상에 내가 하지 않은 일이 있다는 것을 직관적으로 알 수 있어요.
- **공유 캘린더**: 나의 캘린더에 다른 사람이 일정을 등록해줘요. 더이상 메세지를 보고 나의 할 일을 옮겨적지 않아도 돼요.

## 사용 흐름과 사용 방법

1. 이 프로그램은 서버와 클라이언트용 설치 파일 두가지로 나누어져요. 서버용 프로그램에서는 관리자 페이지에 접근이 가능합니다. 관리자 페이지에서 사용자를 등록하고, 학사일정과 학교 공용으로 사용할 그룹 등 기본적인 내용을 저장합니다.
2. 사용자는 서버와 연결하여 서버로부터 정보를 불러올 수 있습니다. 메세지를 전송하거나 일정을 생성하여 다른 사람에게 보내면 그 정보는 서버의 DB에 저장되게 되고, 저장된 DB의 내용은 다른 사용자들의 화면을 구성하는데 활용돼요.

- 사용 환경: PC
- 사용 조건: 관리자 페이지에서 계정 생성 후 무료로 이용 가능함.

## 기술 스택과 실행 방법

- **화면**: HTML, CSS, JS
- **서버·백엔드**: Python, FastAPI
- **AI**: 해당 없음
- **저장소**: SQLite
- **배포**: 설치형 프로그램으로 별도 배포하지 않음

### 폴더 구조

```text
cube/
  backend/
    main.py           # FastAPI 서버 (전체 API 엔드포인트)
  frontend/
    index.html        # 메인 페이지 (캘린더)
    admin.html         # 관리자 페이지
    css/
      style.css
    js/
      auth.js         # 로그인/인증
      calendar.js      # 캘린더
      notice.js        # 공지사항
      notification.js  # 알림
      submission.js    # 제출 현황
      cube-widget.js   # 공통 위젯
database.db            # SQLite DB 파일
seed.py                 # 초기 데이터 시딩 스크립트
requirements.txt         # Python 의존성
README.md
```

### 설치와 실행

```bash
pip install -r requirements.txt
python -m uvicorn backend.main:app --reload
```

- 필요한 환경변수(이름만): 해당없음(환경변수 미사용)

## 교육 현장에서 사용할 때의 주의사항

- **개인정보 처리 여부**: 처리함
- **예상되는 위험**: 학교 안에서  로컬 서버로  데이터를 저장하여 사용하기 때문에 외부 공격에 취약하지 않음
- **위험을 줄이려고 한 일**: 로컬 서버 컴퓨터 관리를 담당자를 정하여 철저히 한다.
- **멈춤 기준**: 공지 전달에 오류가 있을시
- **검증 방법**: 공지 전달 테스트를 주기적으로 한다.
